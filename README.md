# COASTER HOME RUN（試作版）

MSX turbo R 専用の 3D レールシューター。SCREEN 3（マルチカラー 64×48）/ ASCII8 メガロム 128KB / R800 DRAM モード。
仕様は [docs/TrolleyHomeRun_Spec.md](docs/TrolleyHomeRun_Spec.md)、計測と経緯は [docs/検証記録.md](docs/検証記録.md)。

## いまできること

- 起動 → R800 DRAM モード → ROM からエンジンを RAM へ写して実行
- タイトル → オープニング（遊園地からコースターで脱出）→ ステージ 1（丘〜坑道）→ ステージ 2（地底湖）→ ステージ 3（森）→ ステージ 4（町）
  → ステージ 5（村の入り口）→ エンディング（SCREEN 1、ひらがな）→ タイトル
  （宝が尽きたらゲームオーバー → タイトル。宝とスコアはステージをまたいで持ち越す）
- 乗り物はジェットコースターの先頭の車両（視点は低め）。ライフ = 車両の縁の上に積んだ宝の山。被弾すると金貨が飛び散って山が減る。金貨袋を撃つと増える
- オープニング: 獣人の窃盗団が営む遊園地で村の宝を取り返した若者が、コースターの巻き上げと落下の勢いでレールの切れ目からジャンプし、
  柵の外の丘のレールに着地して逃げる。獣人が気づいて後ろから追ってくる（スペースで飛ばせる）
- ステージ 1（炭鉱の坑道）: 手掘りの坑道、坑木の枠組、レールと枕木、カンテラ、落石。左右の折れ曲がりと急な上り下り。
  雑魚 → 中ボス（大猿人の親方）→ 分岐 → 大ボス（洞窟の主: 岩を投げ、ときどき突進）
- ルート分岐: お腹に L / R と書かれた獣人（攻撃しない）の、先に倒した側へ進む。倒さなければ規定の側。
  ステージ 1 は左 = 金貨袋ばかり、右 = 敵ばかり（規定は右）で、約 1 分で元の一本道に戻る
- ステージ 2（地底湖）: 坑道の先の大きな地底湖。レールが途切れ、なぜかコースターごと筏に乗って渡る。鍾乳石と水面の岩。
  岩棚の弓兵、後ろからコウモリ人、水に浮いた木箱の金貨袋、湖の主（大ガエル人: 後ろから追ってきて水の玉を吐き、ときどき跳びかかる）
- ステージ 3（森）: 木の幹と頭上の葉、両側の茂み。キリン人（槍のリーチが長い）、魔法使い（遅い魔法弾）、
  後ろからコウモリ人、金貨袋 2 個、森の番人（巨大コウモリ人: 左右に飛び回り魔法弾を 3 連射）
- ステージ 4（町）: なぜか道に敷かれたレールと両側の家並み。E01〜E05 の混成、後ろから追ってくる猿人、
  祭りの山車（獣人たちが引いて後ろから追ってくる。上の猿人が花火を撃ち、ときどきぶつけてくる）
- ステージ 5（村の入り口）: 通りの突き当たりに村の門と出迎える村人。窃盗団の頭・亜人の王（槍と魔法弾。耐久が半分を切ると 2 倍の速さ）を倒すと門の前で止まる
- エンディング: SCREEN 1 で「わかものは むらの たからものを／とりもどしました。」。持ち帰った宝の量で
  「むらは まえより ゆたかに／もとの くらしに もどり／むらびとは ちょっぴり がっかり」の 3 通り。スコア（残りライフ × 1000 点のボーナス込み）
- 見分けのルール: 敵・敵弾は白の縁取り、金貨袋は黄の縁取り。得点は白い数字が敵の位置に、宝の増減は黄の「+2」・赤の「-1」が宝の山の上に出る
- ステージ 1・2 はやさしい進行（片側の敵が残っている間は反対側から来ない）。3 面以降は前後から容赦なく来る
- 振り向きの警告（ENEMY BEHIND! / ENEMY AHEAD! の点滅と警告音）、字幕、スコア、ステージごとの BGM（PSG ch A/B）、効果音（PSG ch C）

未実装: タイトル・ゲームオーバーの BGM、マウス（TODO）。
フレームレートは openMSX で洞窟 約 15fps、地底湖 約 18fps、森 約 13fps、町 約 15fps、村の入り口 約 16fps（目標 30fps に未達。docs/検証記録.md）。

隠しコンフィグ: タイトルでコナミコマンド（上 上 下 下 左 右 左 右 B A。B・A はキーボードの B キー・A キー）。
被弾で減る宝の数、無敵、ステージセレクト、始めの宝、1 発で倒せる、分岐の固定、やさしい進行、fps 表示を変えられる（仕様書 3.5.3）。

## 操作

| 操作 | キーボード | ジョイスティック（ポート1） |
|---|---|---|
| 照準 | カーソルキー | 方向 |
| 射撃 | スペース | A ボタン |
| 前後切り替え | M または B | B ボタン |

## ビルドと実行

必要なもの: SDCC 4.6（sdcc / sdasz80）、Python 3、openMSX。

```bash
make machine
```

開発用機種 `TH_turboR_dev` を `~/.openMSX/share/machines/` へコピーする（初回のみ）。
C-BIOS を turbo R のハードで動かす機種で、RAM は FS-A1ST と同じスロット 3-0 にある
（3-2 だと openMSX の R800 が 2〜3 倍遅く測れる）。

```bash
make
```

`build/TrolleyHomeRun.rom`（ASCII8、128KB）ができる。

```bash
make run
```

WebMSX で遊ぶときは、ターボR の機種を選び、`build/TrolleyHomeRun [ASCII8].rom` を読み込む
（ファイル名の `[ASCII8]` で WebMSX にマッパーの種類を伝える。自動判定は誤ることがある）。

```bash
make fpsrom
```

計測用 ROM `build/fps/TrolleyHomeRun_FPS [ASCII8].rom` を作る。ゲーム中の左上に fps（直近 1 秒の表示の切替回数）と
直前のフレームのティック数（1 ティック = 1/60 秒）、タイトルに CPU の状態（`CPU:R800 DRAM` / `R800 ROM` / `Z80`。
DRAM モード以外は赤）を出す。WebMSX・実機での計測用。

openMSX で起動して遊ぶ。

```bash
make test RUNDIR=/path/to/scratch
```

約 1 分走らせ、タイトル〜ゲームオーバー〜タイトルを判定する（結果と画面は RUNDIR）。

```bash
make flow RUNDIR=/path/to/scratch GOD=1
```

自動で遊んで（一番手前の敵を狙って撃ち、警告と逆を向いていたら振り向く）、オープニング〜ステージ 5 のボス〜エンディング〜タイトルの
流れを判定する（等速で約 12 分。TIMEOUT=800 などを付ける）。GOD=1 でライフを減らさない（ボス 6 体の撃破とエンディングまでを判定）。

## 構成

```
src/boot/boot.s       ROM bank0: 起動・スロット検出・CPU 切替・ローダー
src/engine/           エンジン。常駐部(RAM 0x4000-0x7FFF)とモジュール(ページ2 0x8000-: 地形 = env.c、ステージごとのゲーム = game.c・models.c・ステージのデータ)
  crt0.s              エンジンの入口
  sys.s               H.TIMI 割り込み・入力・PSG・タイマ
  vdp.s               SCREEN 3 の転送(パック変換つき)
  raster.s            投影と凸多角形の塗り(ホットパス)
  gfx.s math.s        バッファ塗り・矩形、固定小数点演算(MULUW)
  render.c env.c      カメラ・ニアクリップ、トンネル
  rail.c              レール表
  game.c              プレイヤー・敵・当たり判定・スクリプト(ゲームモジュール。敵の動きは表 edef)
  shared.c            常駐部に置くゲームの状態(asm・テストが番地で触るもの)
  modhead_*.s         モジュールの先頭(0x8000 の入口)
  menu.c              タイトルと隠しコンフィグ(ページ0の RAM に置く)
  models.c            敵モデル(gen_data の表と同じくページ0の RAM 0x1A00- に置く。ROM のバンク 1 から起動時に読み込む)
  trolley.c hud.c     乗り物(コースターの車両)の縁と宝の山、文字・ゲージ
  sound.c             効果音ドライバ
src/stage/            ステージデータ(ROM バンク 6 / 8 / 10。RAM 0xB400 へ読み込む)
  stage1_cave.c       ステージ 1: オープニング(遊園地からの脱出)と丘〜坑道
  stage2_lake.c       ステージ 2: 地底湖
  stage3_forest.c     ステージ 3: 森
  stage4_town.c       ステージ 4: 町
  stage5_home.c       ステージ 5: 村の入り口とエンディングの文・BGM
tools/gen_data.py     sin 表・フォント・スプライト・逆数表・コースターの車両の絵
tools/mkrom.py        ROM の組み立て(配置の検査つき)
tools/ressyms.py      常駐部のシンボルをモジュールのリンク用の表にする
tools/test_game.tcl   openMSX の自動テスト
tools/openmsx/        開発用機種定義
```
